# Скелет поверх видео · CV Fitness

Веб-инструмент для отслеживания позы человека в браузере: накладывает скелет (MediaPipe Pose Landmarker) на видео, сравнивает движения с эталоном и даёт «сходство» в процентах. Всё считается локально в браузере — видео и картинка с камеры никуда не отправляются.

## Структура проекта (ES-модули)

- `index.html` — единственная страница: разметка двух режимов, подключает `styles.css` и `js/main.js`.
- `styles.css` — все стили.
- `js/config.js` — константы: CDN, индексы точек, связи-группы, фичи, пресеты упражнений, тиры.
- `js/utils.js` — помощники без состояния: DOM-обёртки, работа с точками, `softSim`/`tierFor`, `beep`, `ensureMeta`.
- `js/dtw.js` — выравнивание временных рядов: `dtwAlign` (оффлайн, полоса Сакоэ–Чибы) и `liveMatch` (живое совпадение с предсказанием лага).
- `js/model.js` — загрузка MediaPipe-модели и WASM с CDN, кэш, локальный `.task`.
- `js/render.js` — отрисовка скелета и канвасов режима «Сравнение».
- `js/singles.js` — режим «Один» (со своим состоянием). Экспортирует `init/stop/loadFile/isRunning`.
- `js/state.js` — общее состояние «Сравнения» (`s` + `cmp`), чтобы модули общались без циклов импортов.
- `js/features.js` — математика сравнения: углы-фичи, видимость, форма-гейт (`syncGate`), веса, сессия.
- `js/score.js` — очки, тиры, комбо, повторы/удержания, графики углов.
- `js/compare.js` — режим «Сравнение»: ввод, камера, tick-цикл, анализ эталона, просмотр, CSV.
- `js/main.js` — точка входа: вкладки, горячие клавиши, drag-and-drop, пресеты.
- `pose_serve.py` — простой статический сервер для ноутбука.
- `pose_qr.py` — QR для телефона: сам поднимает HTTPS-туннель и показывает QR на экране.

## Режимы

- **Один** — скелет поверх одного видео: стили (палочки/полный/неон/прозрачный), фон, цвет, толщина, сглаживание, чекбоксы частей тела, запись результата в файл.
- **Сравнение** — эталон A vs повтор B (файл или камера телефона). Считаются 9 углов (локти, колени, бёдра, наклон корпуса, развод рук, кручение), сходство = взвешенное по видимости среднее от мягкой функции `softSim`: до допуска — 100%, дальше плавный спуск до 0 (частичный кредит за старание, а не ступенька); невидимая часть тела честно снижает счёт. Если человек выполняет **не то движение** (траектории не коррелируют, форма-гейт), фича честно даёт 0. В режиме камеры сравнение идёт со скользящим окном ±2 с (компенсирует задержку повторения), файл-файл — окно 0.5 с. **Оценка действий:** пресеты упражнений (авто/присед/отжимания/выпады/йога-поток/йога-поза/планка) с авто-детектом типа (повторы/фазы/удержание), чипы очков `R1 94%`/`Ф1 92%`, для удержаний — длительность/ошибка угла/дрожь. Игровой **счёт 0–10000** накапливается с нуля по ходу записи (к концу ≈ точность × 10000), комбо ×N — множитель очков (до ×1.2, сброс на промахе «МИМО», при срыве счёт на миг проседает), тиры ОТЛИЧНО/ХОРОШО/ОК/МИМО (85/70/55) показываются рядом с процентом сходства. При загрузке эталона в фоне строится **профиль упражнения** (редкая сетка кадров ~1/с): карточка с типом (повторы/фазы/удержание), акцентом и размахом углов по частям тела, авто-маска снимает с оценки нерабочие части. В живом режиме сходство считается **мягким `softSim` по окну эталона с предсказанием лага** (`liveMatch`: захват лага по всему окну, дальше — полоса вокруг предсказанного времени, дрейф темпа «иногда вместе, иногда с опозданием» больше не режет счёт), веса углов — по реальному размаху эталона, а «сдвиг» показывает отставание в реальном времени. Экспорт в CSV теперь диагностический: сверху JSON со всеми настройками/профилем эталона, ниже — по сэмплам углы, выровненное время, веса, покрытие и накопление счёта. «Прощение задержки» настраивается (0–2 с). Есть обратный отсчёт «Подготовка» (3/5/10 с), графики углов по времени и экспорт в CSV (со счётом, комбо, повторами).

## Запуск

Проект работает только через сервер (ES-модули не открываются с диска напрямую).

Ноутбук:

```
python pose_serve.py
```

Открыть `http://localhost:8000`.

Телефон (нужен HTTPS — камера доступна только в secure-контексте):

```
pip install segno
python pose_qr.py
```

Команда поднимает локальный сервер, запускает https-туннель (`npx localtunnel`, скачается один раз) и открывает в браузере QR-код — отсканируй его телефоном. Ссылка в QR ведёт сразу на `index.html`, камера заработает сразу.

`python pose_qr.py <ссылка>` — просто показать QR для любого URL.
`python pose_qr.py --local` — показать QR для LAN-адреса (без камеры).

## Горячие клавиши (режим «Один»)

`Пробел` пуск/стоп · `Esc` стоп · `B` фон · `S` стиль · `R` запись · `P` число людей · `H` голова · `T` корпус · `A` руки · `L` ноги. В режиме «Сравнение» `Пробел` запускает/останавливает.

## Без сети

Скачайте `pose_landmarker_lite.task` (float16) и укажите его во втором поле файла первого режима.
