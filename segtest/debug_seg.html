debug_seg — авто-сегментация длинного видео

Эксперимент: смена упражнения = устойчивый пик «подписи движения». Обработка без выгрузки куда-либо.
Выбери видео — сбор стартует автоматически.
Белая линия — плейхед видео. Клик по таймлайну — перемотка + признаки ближайшего кадра. Красные полосы — моушн-границы. Цветные полоски — референс (необязательно). Серая полоса внизу — участки без кадров.

Сегменты (авто)

Клик по строке — перемотка к началу сегмента + play. «Автопорог» сам ставит high/low из перцентилей сигнала; сними, чтобы докрутить руками.
